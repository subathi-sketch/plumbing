# BlueRidge Plumbing & Drain: demo site

Single-page demo website for a plumbing company (placeholder content).

- `index.html` is the current site: video banner with a looping animated pipe-repair scene, services carousel, scroll-driven proof cards, About tiles, projects showcase, and contact section.
- `index-realistic.html` is a plain, conventional local-business version.
- `index-animated-backup.html` is an earlier animated version.

No build step: open `index.html` in a browser, or serve the folder (for example `npx serve .`).

Photos are from Unsplash and banner clips from Pexels, loaded from their servers. Names, phone numbers, reviews and the address are placeholders.
